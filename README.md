# skills

Agent skills for Claude Code and any agent that reads `SKILL.md`.

| Skill | Does |
|---|---|
| [workspace-tidy](skills/workspace-tidy) | One layout rule and one read-only audit for a folder full of git repos and worktrees |

## Install

```
npx skills add utkarshchoubeycs/skills --skill <name>
```

Or copy `skills/<name>/` to `~/.claude/skills/<name>/`.
